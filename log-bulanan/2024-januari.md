### What worked well:
- Template harian mempercepat penulisan
- Struktur folder mencegah kebingungan

### Challenges faced:
- Error teknis (file vs folder confusion)
- Butuh waktu adaptasi dengan workflow baru
- Konsistensi membutuhkan disiplin

### Solutions implemented:
- Rename file yang bermasalah
- Buat folder dengan nama berbeda
- Set reminder harian untuk menulis
